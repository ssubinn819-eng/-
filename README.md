# 💅 데이트 장인 언니의 오늘의 데이트 장소 추천

> **"오늘 어디 갈지 각 안 서? 장기연애 8년차 언니의 빅데이터로 실패 없는 100% 성공 코스 찍어줄게!"**

![데이트 장인 언니의 데이트 장소 추천](./og-image.jpg)

오늘의 날씨, 기온, 코디, 원하는 분위기를 선택하면 장기연애 고수 친근한 언니가 연애 고자 동생에게 실패 없는 맞춤 데이트 코스를 콕 집어 추천해주는 인터랙티브 웹 서비스입니다.

---

## ✨ 핵심 기능

1. **실시간 조건 맞춤 추천 엔진**
   - **오늘의 날씨**: 맑음(☀️), 흐림(☁️), 비/눈(🌧️)
   - **오늘의 온도**: -20°C 한파부터 34°C 폭염까지 1°C 단위 슬라이더 조절 & 실시간 기온 멘트
   - **오늘의 코디**: 편함(안꾸 👟), 꾸안꾸(✨), 꾸꾸꾸(💄)
   - **원하는 분위기**: 감성·로맨틱(🍷), 편안·힐링(🌿), 활기·재미(🎢), 특별·이색(🎨)

2. **장기연애 장인 언니의 리얼 멘트**
   - 조건에 맞춰 친근하고 위트 넘치며 자신감 있는 언니 말투로 멘트 동적 생성
   - 날씨, 기온, 착장과 발 피로도까지 세심하게 고려한 실전 팩폭 & 애정 가득 조언

3. **실패 없는 데이트 풀 코스 (1차 → 2차 → 3차)**
   - 악천후(비/눈, 영하 한파, 폭염) 시 **100% 쾌적한 지하철 직결 실내 코스** 우선 배정
   - 화창한 날씨 시 테라스 및 산책로 결합 낭만 코스 배정
   - 장소별 대표 메뉴, 분위기, 이동 동선 최적화

4. **언니의 비기 꿀팁 & 편의 기능**
   - **웨이팅 치트키 & 인생샷 명당 & 대화 스킬** 수록
   - **다른 코스 더 추천해줘 🎲**: 동일 조건 내 다른 추천 코스로 즉시 리롤
   - **코스 복사하기 📋**: 카카오톡 등으로 전송하기 쉬운 포맷으로 원클릭 클립보드 복사
   - **모바일 뷰 / PC 와이드 뷰 토글**: 상단 버튼으로 화면 비율 손쉽게 변경
   - **축하 콘페티(폭죽) & 웹 오디오 효과음**: 별도 음원 파일 없이 경쾌한 인터랙션 제공

## 🛠️ 기술 사양

- **Pure Frontend**: 별도 서버나 외부 데이터베이스 없이 100% 브라우저에서 독립 실행
- **Single File Structure**: `index.html` 단 하나의 파일 안에 HTML, CSS, JavaScript를 모두 포함
- **반응형 & 모바일 퍼스트**: 스마트폰 터치 환경에 최적화된 버튼 크기와 카드 레이아웃
- **Open Graph 메타태그 완비**: 카카오톡, 인스타그램, 페이스북 링크 공유 시 예쁜 썸네일 카드 노출

## 🚀 GitHub Pages로 무료 배포하는 방법

이 프로젝트는 단일 정적 웹페이지이므로 **GitHub Pages**를 이용하면 3분 만에 무료로 전 세계에 서비스할 수 있습니다.

### 방법 1. 깃허브 웹사이트에서 직접 올리기 (가장 쉬움 ⭐)

1. [GitHub](https://github.com)에 로그인 후 우측 상단의 **[+] → [New repository]**를 클릭합니다.
2. **Repository name**에 원하는 이름(예: `date-course-picker` 또는 `anti`)을 입력하고 **Public**으로 설정한 뒤 **[Create repository]**를 누릅니다.
3. 생성된 저장소 화면 중앙에 있는 **"uploading an existing file"** 링크를 클릭합니다.
4. 현재 폴더에 있는 파일들(`index.html`, `og-image.jpg`, `README.md`, `.gitignore`)을 브라우저 화면에 드래그 앤 드롭합니다.
5. 아래쪽의 **[Commit changes]** 초록색 버튼을 클릭합니다.
6. 저장소 상단 메뉴에서 **[Settings]** 탭으로 이동합니다.
7. 좌측 메뉴에서 **[Pages]**를 클릭합니다.
8. **Build and deployment** 항목의 **Branch** 설정을 `None`에서 **`main`**(또는 `master`)으로 변경하고, 우측 폴더는 **`/(root)`** 상태 그대로 둔 뒤 **[Save]**를 클릭합니다.
9. 1~2분 정도 기다린 후 새로고침하면 상단에 **"Your site is live at https://[내깃허브아이디].github.io/[저장소이름]/"** 링크가 생성됩니다! 🎉

---

### 방법 2. Git 터미널 명령어로 올리기

컴퓨터에 `git`이 설치되어 있다면 폴더 위치에서 터미널을 열고 아래 명령어를 순서대로 실행하세요.

```bash
# 1. 로컬 저장소 초기화
git init

# 2. 파일 추가 및 커밋
git add .
git commit -m "feat: 데이트 장인 언니의 데이트 장소 추천 웹 서비스 첫 배포 💕"

# 3. 브랜치명을 main으로 설정
git branch -M main

# 4. 내 깃허브 저장소 주소 연결 (본인 저장소 URL로 변경)
git remote add origin https://github.com/[내깃허브아이디]/[저장소이름].git

# 5. 깃허브로 푸시
git push -u origin main
```

푸시 완료 후, 깃허브 저장소의 **[Settings] → [Pages] → Branch를 `main`으로 선택하고 [Save]**를 누르면 배포가 완료됩니다!
